# Freedom GPT: complete feature tour

This guide describes the upcoming 1.6.0 Windows preview. Current public downloads remain on 1.4.2; the new installers and source are being prepared for publication.

## Free by design

Freedom GPT is free and open source: no subscription, advertising or local per-token fee. Model licenses and external API billing are separate. Local use does not require GitHub, Hugging Face or phone access.

## Code and projects

Build websites and applications: the agent reads and edits files, uses the terminal and runs available checks.

## Goals and task queue

Define an outcome and acceptance criteria. Queue follow-up tasks and steer the current task with an urgent correction.

## Branches and memory

Branch directly from a reply. Keep its conversation and files with a fresh empty queue. Project notes stay on disk.

## Browser beside the chat

The preview opens while the agent works with a page. Review its actions and results; installed tools can also use ordinary browsers.

## Multiple models in one chat

Choose models yourself or allow automatic selection for different stages: scripts, images, video and code.

## Models for your hardware

CPU, RAM, GPU and disk checks help select a model. Interrupted downloads resume and SHA256 hashes verify the files.

## Images and video

View generated media previews in chat. Local generation needs separate models; cloud video supports fal.ai.

## Measured Turbo mode

Compare engine settings on this computer and save an acceleration profile when it helps. Switching waits for an idle model.

## Context and reasoning

Select an available context window and supported reasoning depth. Larger contexts need more memory and may be slower.

## Recovery after tool loops

Full access permits up to three automatic continuations with instructions to change strategy. Unchanged repetitions are blocked; Stop remains effective.

## Phone companion

Enable access in Settings and pair a phone with a QR code. Use chats, files and tasks in the browser while your computer stays on.

## Achievements and levels

Earn achievements, activity counts, XP and Freedom game points. These are local rewards, not an issued cryptocurrency.

## Reply notifications

A small card and a soft chime when a reply is ready, including other chats. Notifications and sound have separate switches on each device. Phone notifications work while the agent page is open.

## Optional accounts and APIs

Use your GitHub account for repository workflows and Hugging Face for compatible model downloads. Local GGUF files also work without signing in. External services may charge separately.

## Your interface

Русский, English and 中文. Light and dark themes, compact settings, expandable tools and update checks at your command.

## Three practical workflows

1. **A website.** Select a project folder and a coding model, define a goal, queue follow-ups, review the preview and confirm a finished result in achievements.
2. **An ad concept.** Use a text model for the script, an image model for source visuals and a compatible video model or fal.ai for clips. Configure available models and costs before enabling automatic routing. External APIs keep their own prices.
3. **Away from your desk.** Keep the PC awake and the app running, pair by QR code and approve on the computer. Continue the same chats in your phone browser. Models run on the PC or the configured API, not on the phone.

## Points and counters

Processed model tokens, generated output tokens and the Freedom game balance are distinct counters. One million processed tokens is an achievement milestone, not one million coins. Each new distinct confirmed website or other result adds to its counter. Automatic metrics and manual confirmations are labelled in the interface.

## Personal Windows experiments

Optional local reading, custom voice cloning and a camera/avatar studio are being developed in the personal Windows profile. Their presence in that profile does not mean they ship in current public installers.

## Practical limits

Quality depends on the model, memory, tools and permissions. Review important results. Local video is experimental. The Mac package remains a preview until native validation is complete. The free phone relay has capacity and transfer limits; background iOS push is not claimed.


## Model connections

The new connection catalog includes OpenRouter, Google Gemini, Groq, Cloudflare Workers AI, OpenAI, DeepSeek, Grok · xAI, Claude · Anthropic, fal.ai. You supply your own API credentials and requests go to your selected provider. Free provider tiers can have changing limits; paid requests follow that provider’s billing.


## Watch the work live

Expand activity to see tool calls, commands and results as the agent works. Send a correction, queue a follow-up or stop the task.


## Applications and Blender

Use installed command-line tools, Python scripts and available app controls, including Blender workflows. The application and its automation tools must be installed and accessible.
