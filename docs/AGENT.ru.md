# Freedom GPT — локальный ИИ-агент

**Модель + инструменты + память проекта.** Вы описываете результат, агент работает с доступными инструментами и показывает сделанное. Бесплатно и с открытым исходным кодом. Для локальных запросов подписка не нужна.

## Новое в версии 1.5.0

Версия 1.5.0 добавляет перечисленные возможности. Прежние релизы остаются доступными. Для обновления нажмите «Проверить обновления», когда будете готовы.

| Возможность | Как пользоваться |
|---|---|
| Цель | Кнопка с прицелом: результат, критерии и ограничения. Продолжение после хода, пауза, история и повторная активация. Счётчик шагов не ограничивает цель двадцатью ходами. |
| Очередь | Пишите во время работы. Редактируйте промпт, перемещайте или удаляйте будущие задания. Срочную поправку отправляйте в текущий ход. |
| Память | История и проектные записи остаются на диске. Агент подбирает нужные фрагменты после сжатия, перезапуска и смены модели. Это конечный контекст, а не безошибочная вечная память. |
| Ветки | Начните отдельную задачу на основе переписки и файлов исходного чата. У ветки своя пустая очередь. |
| Навыки | Сохраняйте повторяемые рабочие инструкции. Это инструкции и примеры, а не переобучение весов. |
| Браузер | Просмотр рядом с чатом, снимки страницы и визуальная проверка совместимой моделью. Внешние сайты требуют интернета. |
| Приложения и 3D | Терминал, скрипты и установленные интеграции позволяют работать с приложениями, включая Blender. Blender и специализированные инструменты устанавливаются отдельно; наличие программы само по себе не гарантирует управление любым её окном. |
| Файлы и медиа | Сворачиваемый список, просмотр, правка поддерживаемых текстовых файлов и обратимое удаление. Картинки и видео показываются превью. |
| Модели | Проверка RAM, VRAM и диска, подбор по задаче, каталог и возобновляемые загрузки. Свои совместимые GGUF можно добавить без регистрации. Не всякая архитектура и квантование поддерживаются движком. |
| GitHub | Необязательный PAT или явный вход через существующий GitHub CLI. Чтение; запись в репозитории, ветки, коммиты, PR и issues — с отдельным разрешением и правами токена. |
| Hugging Face | Необязательный Read-токен для доступных аккаунту моделей. Для закрытых моделей отдельно принимаются условия владельца. Открытые модели доступны без входа. |
| API | Дополнительные поддерживаемые провайдеры при наличии интернета и своего ключа. Бесплатные квоты могут меняться; бесплатный чат провайдера не означает бесплатный API. |
| Награды | Достижения, уровни, XP и локальные игровые баллы Freedom за подтверждённые результаты. Не криптовалюта, не денежный баланс и не обещание обмена. |
| Обновления | По кнопке «Проверить обновления». Проверка подписи и SHA256; установка ожидает свободного агента и сохраняет данные. |

## С чего начать

1. Установите сборку для своей ОС. На Mac сборка пока экспериментальная и требует проверки на настоящем устройстве.
2. Проверьте ПК, выберите совместимую модель и дождитесь загрузки с проверкой.
3. Выберите папку проекта. Начните с небольшого запроса и проверьте вызов инструментов.
4. Для большой задачи включите цель и укажите, как проверить готовность.
5. Проверяйте файлы и результаты, сохраняйте Git и резервные копии.

Пример: «Создай локальный сайт в папке проекта. Сначала план, затем реализация и тесты. Покажи страницу в просмотре. Перед публикацией остановись».

## Сценарий агента разработки

Чаты, терминал, файлы, очередь, поправки, ветки и визуальный просмотр знакомы пользователям агентов разработки. Freedom GPT добавляет выбор собственных совместимых моделей и локальные вычисления. Сравнительное качество с Codex или другим продуктом не измерено: установленная небольшая модель может ошибаться чаще сильной облачной. Скорость зависит от ПК, модели и контекста; 100+ токенов/с не гарантируются.

Публичная сборка не включает личный набор всех утилит автора. Внешние действия требуют интернета, соответствующих доступов и ответственности пользователя.
