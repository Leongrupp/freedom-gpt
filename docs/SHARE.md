## English · short introduction

**Freedom GPT is a free, open-source local AI workspace for your own computer.**
Chat, code, work with files and generate images using compatible downloaded
models. Local inference needs no subscription or paid API. Windows and Ubuntu
packages include Python and engines; an Apple Silicon Mac preview is available.
Model weights download separately and keep their own licenses. Local work can
run offline after setup; web tools, downloads and updates need internet.

[Explore and download](https://aionpc.ru/en/) · [Source code](https://github.com/Leongrupp/freedom-gpt)

Useful feedback, hardware/model compatibility reports and focused contributions
are welcome. If the project helps you, consider sharing it or giving it a genuine
GitHub star 💛

## Русский · коротко о проекте

**Freedom GPT — бесплатные локальные нейросети на вашем ПК, с открытым кодом.**
Чат, программирование, файлы и изображения с совместимыми скачанными моделями.
У локальных запросов нет подписки и обязательного платного API. В сборках Windows
и Ubuntu уже есть Python и движки; для Apple Silicon доступна тестовая сборка Mac.
Веса моделей скачиваются отдельно и имеют собственные лицензии. После настройки
локальная работа доступна офлайн, а сетевые инструменты требуют интернета.

[Посмотреть и скачать](https://aionpc.ru/) · [Исходный код](https://github.com/Leongrupp/freedom-gpt)

Буду рад отзывам, результатам на разных ПК и небольшим полезным PR. Если проект
помогает, поделитесь ссылкой или поддержите его настоящей звездой GitHub 💛

## Important context / Важно сохранить

- The app is MIT-licensed; models and components have separate licenses.
- Local computation uses the user's hardware, electricity and storage.
- Native Mac execution is unverified. The candidate requires M1+ and macOS 26.2+ and is unsigned/not notarized.
- Video Studio is experimental. See [actual validation](../VERIFICATION.md).
- No claim of universal speed, unlimited context, free proprietary cloud models or affiliation with their vendors.
- These texts are prepared for sharing. No outreach to other projects or communities is performed by this file.
