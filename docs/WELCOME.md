# Welcome to Freedom GPT / Добро пожаловать 💛

Freedom GPT is a free, open-source workspace for running compatible AI models
on your own computer. Local chat, code, files and image generation live in one
interface. Local inference needs no subscription or paid cloud API.

## Start here

**[Website and downloads](https://aionpc.ru/en/)** · **[Installation guide](https://github.com/Leongrupp/freedom-gpt/blob/main/INSTALL.md)** · **[Choose a model](https://aionpc.ru/en/guides/choose-model/)**

- Windows 10/11 x64: installer or portable ZIP.
- Ubuntu 24.04 x64: .run, DEB or TAR.GZ.
- Mac: experimental Apple Silicon build, M1+ / macOS 26.2+, unsigned; native execution not yet verified.

Python and engines are bundled. Model weights download separately and keep
their own licenses. Downloaded local models can work offline; web tools and
updates need internet. Quality and speed depend on your model and hardware.
Video Studio is experimental; see the [actual checks and limits](https://github.com/Leongrupp/freedom-gpt/blob/main/VERIFICATION.md).

## What would help most?

1. Tell us which OS, hardware and model you tried, and what actually worked.
2. Share a useful coding or creative workflow, without private project data.
3. Suggest a model or a clearer installation step.
4. Submit a reproducible bug through the [issue forms](https://github.com/Leongrupp/freedom-gpt/issues/new/choose).
5. Contribute a translation or a focused improvement.

If Freedom GPT is useful to you, a genuine star or sharing the project with
someone who needs local AI means a lot. Thank you for helping it grow 💛

## По-русски

Freedom GPT — бесплатное приложение с открытым кодом для локальных нейросетей
на вашем компьютере. Для локальных запросов не нужны подписка и платный API.
Модели скачиваются отдельно; нужны ваше железо, электричество и место на диске.
