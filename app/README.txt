FREEDOM GPT
===========

Run FreedomGPT.exe. Choose a model after the hardware check, download it and
wait for verification. Switch RU/EN in the top-right corner or Settings.
Image generation requires its separate model set. Fast code and Think are
separate modes. Automatic signed updates install between tasks and preserve
chats, models and settings. You can disable them in Settings.

Запустите FreedomGPT.exe. После проверки ПК выберите модель, скачайте её и
дождитесь проверки. Язык RU/EN переключается сверху справа и в настройках.
Для рисования нужен отдельный комплект. Код: «Код — быстро» или «Обдумать».
Подписанные обновления устанавливаются между задачами и сохраняют ваши данные.

Keep the complete folder together. Run Stop-FreedomGPT.cmd before unplugging
an SSD or making a backup. Не отключайте SSD во время работы приложения.
Local inference works offline after downloading models. Downloads, websites
and update checks need internet. Установщик не подписан Authenticode.
Review generated code and run tests. Проверяйте сгенерированный код тестами.
