# Support / Поддержка

Freedom GPT is an independent free project. English and Russian are welcome.
Это независимый бесплатный проект. Можно писать по-русски и по-английски.

| Need / Задача | Where / Куда |
| :--- | :--- |
| Install the app / Установить | [Step-by-step guides / Пошагово](https://aionpc.ru/#installation) |
| Choose a model / Выбрать модель | [Hardware and model guide](https://aionpc.ru/en/guides/choose-model/) · [Русский](https://aionpc.ru/guides/choose-model/) |
| Reproducible bug / Повторяемая ошибка | [Bug form / Форма ошибки](https://github.com/Leongrupp/freedom-gpt/issues/new/choose) |
| Questions, workflows, model ideas / Вопросы и идеи | [GitHub Discussions](https://github.com/Leongrupp/freedom-gpt/discussions) |
| Contact the author / Написать автору | [Telegram @AI1rus](https://t.me/AI1rus) |
| Security issue / Уязвимость | Read [SECURITY.md](SECURITY.md); report privately when available. |

For a useful bug report, include the app version, OS, CPU/RAM/GPU/VRAM, model,
quantization and steps to repeat the issue. Share a short relevant log excerpt
with private data removed. Never post passwords, keys, cookies or customer data.

Для отчёта об ошибке укажите версию приложения, ОС, процессор, RAM, видеокарту,
VRAM, модель, квантование и шаги повторения. Удалите личные данные из журналов.

The Mac build and Video Studio have published limitations. Please read
[CROSS-PLATFORM.md](CROSS-PLATFORM.md) and [VERIFICATION.md](VERIFICATION.md)
before planning work. There is no guaranteed response time or support SLA.
