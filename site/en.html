01

Code and real project files

Ask for a website or application. With available terminal tools, the agent can edit files, run commands and tests, explain changes and return to the project.

02

A goal beyond one reply

Define an outcome and acceptance criteria. The agent checks its goal after a turn and can continue working. Pause it, inspect history or reactivate a goal whose result you have not accepted.

03

Queue and steering

Send follow-up tasks while work is in progress. Reorder, edit or remove queued prompts, and send an urgent correction to the current task.

04

Memory, branches and skills

History and project notes stay on disk. Branch a conversation, save working instructions as skills and switch compatible models within a chat.

05

Browser and applications

Inspect a website beside the chat. The agent can take snapshots and check the page. Installed tools and scripts can also drive applications, including Blender for 3D work.

06

Your choice of models

Hardware checks suggest options for code, chat, vision and video. Use compatible GGUF files and optional Hugging Face, GitHub and supported API connections.

Advanced: download and install through Terminal⌘

Open PowerShell in a download folder. Paste the entire block. It downloads this release from GitHub, checks SHA256 and starts it. Enter a new empty SSD folder when asked. This creates a portable installation; no separate Python is needed.

PowerShell
& {
  $ErrorActionPreference = 'Stop'
  $freedomInstallPath = Read-Host 'New empty SSD folder (for example D:\FreedomGPT)'
  if ([string]::IsNullOrWhiteSpace($freedomInstallPath)) { throw 'Choose an empty folder.' }
  $freedomInstallPath = [IO.Path]::GetFullPath($freedomInstallPath)
  $freedomSetupPath = Join-Path (Get-Location) 'FreedomGPT-Setup-1.5.0.exe'
  $freedomHash = 'fb3e319c5223efda6efb97d3ab150cef2c3f7a1a853595ee10e371d4670844d1'
  if (!(Test-Path -LiteralPath $freedomSetupPath) -or (Get-FileHash -LiteralPath $freedomSetupPath -Algorithm SHA256).Hash -ne $freedomHash) {
    curl.exe -fL -C - --retry 4 -o $freedomSetupPath 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.5.0/FreedomGPT-Setup-1.5.0.exe'
    if ($LASTEXITCODE -ne 0) { throw 'Download failed. Run again to resume.' }
  }
  if ((Get-FileHash -LiteralPath $freedomSetupPath -Algorithm SHA256).Hash -ne $freedomHash) { throw 'SHA256 mismatch. Installation stopped.' }
  $freedomProcess = Start-Process -FilePath $freedomSetupPath -ArgumentList ('/extract="' + $freedomInstallPath + '"') -Wait -PassThru
  if ($freedomProcess.ExitCode -ne 0) { throw 'Installation failed. Choose a new empty folder outside your user profile.' }
  Start-Process -FilePath (Join-Path $freedomInstallPath 'FreedomGPT.exe')
}

If one-click copy is unavailable: Select → Ctrl+C (Cmd+C on Mac).

Advanced: download and install through Terminal⌘

Open macOS Terminal in a download folder. Paste the entire block. It downloads this release from GitHub, checks SHA256 and starts it. These commands have not been executed on a physical Mac. OS approval may still be required.

macOS Terminal
(
  set -eu
  [ "$(uname -m)" = arm64 ] || { echo 'Apple Silicon is required.'; exit 1; }
  sw_vers -productVersion | awk -F. '{ exit !($1 > 26 || ($1 == 26 && $2 >= 2)) }' || { echo 'macOS26.2+ is required.'; exit 1; }
  freedom_file='FreedomGPT-1.5.0-macOS-AppleSilicon.zip'
  freedom_sha='d847ea54519b4839392d77311c2e42241d4b1759ed6f99f00223b3571adac650'
  freedom_folder='./FreedomGPT-1.5.0-macOS'
  [ ! -e "$freedom_folder" ] || { echo 'The extraction folder already exists. Choose a new folder.'; exit 1; }
  if ! printf '%s  %s\n' "$freedom_sha" "$freedom_file" | shasum -a 256 -c - >/dev/null 2>&1; then
    curl -fL -C - --retry 4 -o "$freedom_file" 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.5.0/FreedomGPT-1.5.0-macOS-AppleSilicon.zip'
  fi
  printf '%s  %s\n' "$freedom_sha" "$freedom_file" | shasum -a 256 -c -
  ditto -x -k "$freedom_file" "$freedom_folder"
  open "$freedom_folder/Freedom GPT.app"
)

FAQ

A few good questions.

Is Freedom GPT really free?+

Yes. The application is free, its source code is MIT-licensed, and local inference has no subscription or per-token charge. You provide hardware, electricity and storage. Models have separate licenses.

Does it work offline?+

Yes, for local chat and files after the models are downloaded. Search, websites, downloads and update checks need internet.

Will it always generate 100+ tokens per second?+

No. Speed depends on hardware, model and context length. One tested long code answer on an RTX 4080 measured 100.85 tokens/s. This is a case-specific result, not a guarantee. Review code and run tests.

What about licenses?+

Application source is MIT. Bundled components retain their licenses and notices; model licenses are separate. The clean installer includes no personal history or credentials from the author.

How does the new agent version update?+

Checking and downloading start only when you click Check for updates. Signed installation waits for idle tasks and preserves user data.
