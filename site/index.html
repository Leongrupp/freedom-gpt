Выбирайте доступное окно контекста и поддерживаемую глубину обдумывания. Большое окно требует больше памяти и может работать медленнее.

10

Продолжение после ошибок

При полном доступе агент получает до трёх автоматических продолжений со сменой подхода. Повтор без исправлений блокируется; кнопка «Стоп» действует.

11

Достижения, счётчики работ, опыт и игровые баллы Freedom. Это локальные награды, а не выпущенная криптовалюта.

Для опытных: скачать и установить через терминал⌘

Откройте PowerShell в папке для загрузок. Вставьте блок целиком: он скачает сборку из GitHub, проверит SHA256 и запустит её. Когда появится запрос, укажите новую пустую папку на SSD вне папки пользователя. Это переносимая установка; отдельный Python не нужен.

PowerShell
& {
  $ErrorActionPreference = 'Stop'
  $freedomInstallPath = Read-Host 'New empty SSD folder (for example D:\FreedomGPT)'
  if ([string]::IsNullOrWhiteSpace($freedomInstallPath)) { throw 'Choose an empty folder.' }
  $freedomInstallPath = [IO.Path]::GetFullPath($freedomInstallPath)
  $freedomSetupPath = Join-Path (Get-Location) 'FreedomGPT-Setup-1.4.2.exe'
  $freedomHash = 'c7862b0c5e90ebcf454b405fa84047c76c966cd2346e1dae25392574dcd4317a'
  if (!(Test-Path -LiteralPath $freedomSetupPath) -or (Get-FileHash -LiteralPath $freedomSetupPath -Algorithm SHA256).Hash -ne $freedomHash) {
    curl.exe -fL -C - --retry 4 -o $freedomSetupPath 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.4.2/FreedomGPT-Setup-1.4.2.exe'
    if ($LASTEXITCODE -ne 0) { throw 'Download failed. Run again to resume.' }
  }
  if ((Get-FileHash -LiteralPath $freedomSetupPath -Algorithm SHA256).Hash -ne $freedomHash) { throw 'SHA256 mismatch. Installation stopped.' }
  $freedomProcess = Start-Process -FilePath $freedomSetupPath -ArgumentList ('/extract="' + $freedomInstallPath + '"') -Wait -PassThru
  if ($freedomProcess.ExitCode -ne 0) { throw 'Installation failed. Choose a new empty folder outside your user profile.' }
  Start-Process -FilePath (Join-Path $freedomInstallPath 'FreedomGPT.exe')
}

Если копирование по кнопке недоступно: «Выделить» → Ctrl+C (Cmd+C на Mac).

Для опытных: скачать и установить через терминал⌘

Откройте macOS Terminal в папке для загрузок. Вставьте блок целиком: он скачает сборку из GitHub, проверит SHA256 и запустит её. Эти команды ещё не выполнялись на настоящем Mac. Может потребоваться ручное разрешение macOS.

macOS Terminal
(
  set -eu
  [ "$(uname -m)" = arm64 ] || { echo 'Apple Silicon is required.'; exit 1; }
  sw_vers -productVersion | awk -F. '{ exit !($1 > 26 || ($1 == 26 && $2 >= 2)) }' || { echo 'macOS26.2+ is required.'; exit 1; }
  freedom_file='FreedomGPT-1.4.2-macOS-AppleSilicon.zip'
  freedom_sha='361c4703cb45f5c44c8b9bd2a4a4cb9a817b1cb9380a16ab9fb52cd75caf1d71'
  freedom_folder='./FreedomGPT-1.4.2-macOS'
  [ ! -e "$freedom_folder" ] || { echo 'The extraction folder already exists. Choose a new folder.'; exit 1; }
  if ! printf '%s  %s\n' "$freedom_sha" "$freedom_file" | shasum -a 256 -c - >/dev/null 2>&1; then
    curl -fL -C - --retry 4 -o "$freedom_file" 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.4.2/FreedomGPT-1.4.2-macOS-AppleSilicon.zip'
  fi
  printf '%s  %s\n' "$freedom_sha" "$freedom_file" | shasum -a 256 -c -
  ditto -x -k "$freedom_file" "$freedom_folder"
  open "$freedom_folder/Freedom GPT.app"
)

Если копирование по кнопке недоступно: «Выделить» → Ctrl+C (Cmd+C на Mac).

(

FAQ

Есть вопросы?

Это бесплатно?+

Да. Freedom GPT бесплатен, с открытым кодом, без подписки, рекламы и оплаты локальных токенов. Нужен ваш компьютер; веса моделей скачиваются отдельно. У сторонних API свои тарифы.

Можно управлять с iPhone?+

В новой версии есть необязательный доступ через браузер: QR-код и подтверждение на компьютере. ПК должен работать, не спать и иметь интернет. Приложение из App Store не требуется. Связь идёт через сервер проекта с ограничениями нагрузки.

Игровые Freedom — это криптовалюта?+

Пока это локальные игровые баллы и достижения. Сейчас их нельзя переводить, продавать или обменивать. Будущая стоимость или конвертация не обещается.

Подойдёт ли мой компьютер?+

Программа проверяет CPU, RAM, GPU и место на диске и предлагает модели. Небольшие модели требуют меньше памяти. Реальная скорость и качество зависят от вашего железа, модели и размера контекста.

Работает без интернета?+

После загрузки моделей — да, для локального чата и файлов. Поиск, сайты, загрузки и проверка обновлений требуют сети.

Что с лицензиями?+

Код приложения — MIT. У компонентов сохранены отдельные лицензии и сведения об авторах. У моделей свои лицензии. В установщике нет личной истории или ключей автора.

Как обновляется новая версия агента?+

Проверка и загрузка начинаются только по кнопке «Проверить обновления». Подписанная установка ждёт завершения задач и сохраняет пользовательские данные.
