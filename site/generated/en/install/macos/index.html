Freedom GPT for Mac: Apple Silicon preview

Open-source local AI preview for Apple Silicon M1+ and macOS 26.2+. Download the app ZIP and read requirements and unverified-platform limitations.

Content checked: 21.10.2026 · v1.5.0

This is an experimental Apple Silicon build, requiring M1 or newer and macOS 26.2+. It does not support Intel Macs. The package is unsigned and not notarized; execution on a physical Mac has not been verified. Read these limits before downloading.

Download for Mac ↓FreedomGPT-1.5.0-macOS-AppleSilicon.zip · 0.31 GB · GitHub

Installation steps

  1. Check your Mac

    The preview requires Apple Silicon M1+ and macOS 26.2+. Intel Mac is not supported.

  2. Unpack the ZIP

    Click “Download for Mac”, unpack the ZIP and move Freedom GPT.app into Applications.

  3. Open the application

    Open Freedom GPT.app. The unsigned preview may require manual OS approval; native Mac execution is not yet verified.

Before first launch

Unpack the complete app bundle. macOS may require approval through its standard security interface. This guide does not ask you to disable Gatekeeper or remove quarantine attributes. Native performance, image generation and video have not been validated on Mac.

Terminal installation

Paste the entire block in Terminal. It downloads the official release with resume support and verifies SHA256 before launching. These commands have not been executed on a physical Mac.

Terminal
(
  set -eu
  [ "$(uname -m)" = arm64 ] || { echo 'Apple Silicon is required.'; exit 1; }
  sw_vers -productVersion | awk -F. '{ exit !($1 > 26 || ($1 == 26 && $2 >= 2)) }' || { echo 'macOS26.2+ is required.'; exit 1; }
  freedom_file='FreedomGPT-1.5.0-macOS-AppleSilicon.zip'
  freedom_sha='6a25cec10e906659c6f0106273ee63e3f3e0dc8bd11998e36cf129094d70908b'
  freedom_folder='./FreedomGPT-1.5.0-macOS'
  [ ! -e "$freedom_folder" ] || { echo 'The extraction folder already exists. Choose a new folder.'; exit 1; }
  if ! printf '%s  %s\n' "$freedom_sha" "$freedom_file" | shasum -a 256 -c - >/dev/null 2>&1; then
    curl -fL -C - --retry 4 -o "$freedom_file" 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.5.0/FreedomGPT-1.5.0-macOS-AppleSilicon.zip'
  fi
  printf '%s  %s\n' "$freedom_sha" "$freedom_file" | shasum -a 256 -c -
  ditto -x -k "$freedom_file" "$freedom_folder"
  open "$freedom_folder/Freedom GPT.app"
)

If one-click copy is unavailable: Select → Ctrl+C (Cmd+C on Mac).

Choose a first model

Model weights are separate from the installer. Let the application inspect RAM, VRAM and storage, then select a model that fits. Start with a small model on a low-memory PC. Downloading requires internet; local chat can work offline afterwards. Model sizes and memory guide.
