Free local AI for Windows

Install Freedom GPT on Windows 10/11. Free local AI with no subscription, bundled Python, EXE or portable ZIP, and verified PowerShell commands.

Content checked: 21.10.2026 · v1.5.0

Install a local AI workspace on Windows 10 or 11 x64. Python, Node.js and inference engines are included. You do not need to create an account or subscribe to run local models.

Download for Windows ↓FreedomGPT-Setup-1.5.0.exe · 1.62 GB · GitHub

Installation steps

  1. Download the app

    Click “Download for Windows” on this page. Open the downloaded EXE file.

  2. Choose a folder

    Select your language and a new empty SSD folder, then click Install.

  3. Start your first chat

    Open FreedomGPT.exe or the shortcut. The app checks your PC; choose and download a model.

EXE or ZIP?

EXE is the recommended graphical installer. ZIP is a portable folder: extract the entire archive into a new SSD folder and start FreedomGPT.exe. Copying only the EXE from the ZIP is not enough. Use a new installation folder; keep existing chats and model files.

Terminal installation

Paste the entire block in PowerShell. It downloads the official release with resume support and verifies SHA256 before launching. Enter a new empty SSD folder outside your user profile when prompted. This creates a portable installation.

PowerShell
& {
  $ErrorActionPreference = 'Stop'
  $freedomInstallPath = Read-Host 'New empty SSD folder (for example D:\FreedomGPT)'
  if ([string]::IsNullOrWhiteSpace($freedomInstallPath)) { throw 'Choose an empty folder.' }
  $freedomInstallPath = [IO.Path]::GetFullPath($freedomInstallPath)
  $freedomSetupPath = Join-Path (Get-Location) 'FreedomGPT-Setup-1.5.0.exe'
  $freedomHash = 'fb3e319c5223efda6efb97d3ab150cef2c3f7a1a853595ee10e371d4670844d1'
  if (!(Test-Path -LiteralPath $freedomSetupPath) -or (Get-FileHash -LiteralPath $freedomSetupPath -Algorithm SHA256).Hash -ne $freedomHash) {
    curl.exe -fL -C - --retry 4 -o $freedomSetupPath 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.5.0/FreedomGPT-Setup-1.5.0.exe'
    if ($LASTEXITCODE -ne 0) { throw 'Download failed. Run again to resume.' }
  }
  if ((Get-FileHash -LiteralPath $freedomSetupPath -Algorithm SHA256).Hash -ne $freedomHash) { throw 'SHA256 mismatch. Installation stopped.' }
  $freedomProcess = Start-Process -FilePath $freedomSetupPath -ArgumentList ('/extract="' + $freedomInstallPath + '"') -Wait -PassThru
  if ($freedomProcess.ExitCode -ne 0) { throw 'Installation failed. Choose a new empty folder outside your user profile.' }
  Start-Process -FilePath (Join-Path $freedomInstallPath 'FreedomGPT.exe')
}

If one-click copy is unavailable: Select → Ctrl+C (Cmd+C on Mac).

Choose a first model

Model weights are separate from the installer. Let the application inspect RAM, VRAM and storage, then select a model that fits. Start with a small model on a low-memory PC. Downloading requires internet; local chat can work offline afterwards. Model sizes and memory guide.
