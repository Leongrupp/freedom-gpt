Freedom GPT для Mac: тестовая сборка

Открытый локальный ИИ для Apple Silicon M1+ и macOS 26.2+. ZIP со средой, ограничения тестовой сборки и инструкция установки.

Материал проверен: 22.10.2026 · v1.4.2

Это экспериментальная сборка для Apple Silicon M1 и новее, требуется macOS 26.2+. Для Intel Mac она не подходит. Пакет без подписи и нотарификации; запуск на настоящем Mac ещё не проверен. Учитывайте эти ограничения перед загрузкой.

Установка по шагам

  1. Проверьте свой Mac

    Тестовая сборка требует Apple Silicon M1+ и macOS 26.2+. Для Intel Mac она не подходит.

  2. Распакуйте ZIP

    Нажмите «Скачать для Mac», распакуйте ZIP и перенесите Freedom GPT.app в «Программы».

  3. Откройте приложение

    Запустите Freedom GPT.app. Для сборки без подписи может потребоваться ручное разрешение macOS; запуск на настоящем Mac ещё не проверен.

Перед первым запуском

Распакуйте приложение целиком. macOS может запросить разрешение через штатный интерфейс безопасности. Инструкция не требует отключать Gatekeeper или удалять атрибут карантина. Производительность, генерация изображений и видео на Mac пока не подтверждены.

Установка через терминал

Вставьте блок целиком в терминал. Он скачает официальный релиз с поддержкой продолжения загрузки и проверит SHA256 перед запуском. Эти команды ещё не выполнялись на настоящем Mac.

Terminal
(
  set -eu
  [ "$(uname -m)" = arm64 ] || { echo 'Apple Silicon is required.'; exit 1; }
  sw_vers -productVersion | awk -F. '{ exit !($1 > 26 || ($1 == 26 && $2 >= 2)) }' || { echo 'macOS26.2+ is required.'; exit 1; }
  freedom_file='FreedomGPT-1.4.2-macOS-AppleSilicon.zip'
  freedom_sha='361c4703cb45f5c44c8b9bd2a4a4cb9a817b1cb9380a16ab9fb52cd75caf1d71'
  freedom_folder='./FreedomGPT-1.4.2-macOS'
  [ ! -e "$freedom_folder" ] || { echo 'The extraction folder already exists. Choose a new folder.'; exit 1; }
  if ! printf '%s  %s\n' "$freedom_sha" "$freedom_file" | shasum -a 256 -c - >/dev/null 2>&1; then
    curl -fL -C - --retry 4 -o "$freedom_file" 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.4.2/FreedomGPT-1.4.2-macOS-AppleSilicon.zip'
  fi
  printf '%s  %s\n' "$freedom_sha" "$freedom_file" | shasum -a 256 -c -
  ditto -x -k "$freedom_file" "$freedom_folder"
  open "$freedom_folder/Freedom GPT.app"
)

Если копирование по кнопке недоступно: «Выделить» → Ctrl+C (Cmd+C на Mac).

Выберите первую модель

Веса моделей не входят в установщик. Дождитесь проверки RAM, VRAM и диска и выберите подходящую модель. На ПК с небольшой памятью начните с лёгкого варианта. Для загрузки нужен интернет; затем локальный чат может работать офлайн. Размеры моделей и требования к памяти.
