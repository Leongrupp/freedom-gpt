Бесплатный ИИ для Ubuntu Linux

Скачайте Freedom GPT для Ubuntu 24.04 x64: установщик .run, DEB и TAR.GZ. Python и движки внутри, выбор локальной модели по памяти ПК.

Материал проверен: 22.10.2026 · v1.4.2

Сборка рассчитана на Ubuntu 24.04 x64. В установщике есть среда Python, Node.js и движки. Видеодрайвер устанавливается отдельно. Установка проверена в чистом контейнере; это не подтверждает работу каждой видеокарты и конфигурации рабочего стола.

Установка по шагам

  1. Скачайте установщик

    Нажмите «Скачать для Ubuntu». Рекомендуемый файл заканчивается на .run.

  2. Запустите через терминал

    Откройте терминал в папке со скачанным файлом. Скопируйте и выполните короткую команду ниже.

  3. Выберите модель

    Дождитесь открытия приложения. Оно проверит компьютер и предложит подходящие модели.

Ubuntu · скачанный файл
sh ./FreedomGPT-Setup-1.4.2-Ubuntu-x64.run

Если копирование по кнопке недоступно: «Выделить» → Ctrl+C (Cmd+C на Mac).

Другие форматы пакетов

Выберите .run для обычной установки. DEB предназначен для установки пакетным менеджером, TAR.GZ — для ручного размещения. Само приложение запускайте от обычного пользователя. Для приложения и весов моделей понадобится свободное место на диске.

Установка через терминал

Вставьте блок целиком в терминал. Он скачает официальный релиз с поддержкой продолжения загрузки и проверит SHA256 перед запуском. Нужен curl. Если он отсутствует, скачайте файл кнопкой и выполните короткую команду выше.

Terminal
(
  set -eu
  freedom_file='FreedomGPT-Setup-1.4.2-Ubuntu-x64.run'
  freedom_sha='c6e4100867c74ee963f32cddbeb2ad3191562f791ee22e2cd64bace82e684910'
  if ! printf '%s  %s\n' "$freedom_sha" "$freedom_file" | sha256sum -c - >/dev/null 2>&1; then
    curl -fL -C - --retry 4 -o "$freedom_file" 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.4.2/FreedomGPT-Setup-1.4.2-Ubuntu-x64.run'
  fi
  printf '%s  %s\n' "$freedom_sha" "$freedom_file" | sha256sum -c -
  sh "./$freedom_file"
)

Если копирование по кнопке недоступно: «Выделить» → Ctrl+C (Cmd+C на Mac).

Выберите первую модель

Веса моделей не входят в установщик. Дождитесь проверки RAM, VRAM и диска и выберите подходящую модель. На ПК с небольшой памятью начните с лёгкого варианта. Для загрузки нужен интернет; затем локальный чат может работать офлайн. Размеры моделей и требования к памяти.
