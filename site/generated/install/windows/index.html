Бесплатный локальный ИИ для Windows

Установка Freedom GPT на Windows 10/11: бесплатный локальный ИИ без подписки, Python внутри, модели отдельно. EXE, ZIP и команды PowerShell.

Материал проверен: 23.10.2026 · v1.6.0

Установите локальное пространство ИИ на Windows 10 или 11 x64. Python, Node.js и движки уже включены. Для локальной работы не нужно создавать аккаунт или оформлять подписку.

Скачать для Windows ↓FreedomGPT-Setup-1.6.0.exe · 1.62 GB · GitHub

Установка по шагам

  1. Скачайте приложение

    Нажмите «Скачать для Windows» на этой странице. Откройте скачанный EXE-файл.

  2. Выберите папку

    Выберите язык и новую пустую папку на SSD, затем нажмите «Установить».

  3. Начните первый чат

    Откройте FreedomGPT.exe или ярлык. Приложение проверит ПК — выберите и скачайте модель.

Что выбрать: EXE или ZIP?

EXE — основной установщик с выбором языка и папки. ZIP — переносимая папка: полностью распакуйте архив на SSD и запустите FreedomGPT.exe. Одного EXE, вынутого из ZIP, недостаточно. Для новой установки выбирайте новую папку; сохраняйте существующие чаты и модели.

Установка через терминал

Вставьте блок целиком в PowerShell. Он скачает официальный релиз с поддержкой продолжения загрузки и проверит SHA256 перед запуском. При запросе укажите новую пустую папку на SSD вне папки пользователя. Будет создана переносимая установка.

PowerShell
& {
  $ErrorActionPreference = 'Stop'
  $freedomInstallPath = Read-Host 'New empty SSD folder (for example D:\FreedomGPT)'
  if ([string]::IsNullOrWhiteSpace($freedomInstallPath)) { throw 'Choose an empty folder.' }
  $freedomInstallPath = [IO.Path]::GetFullPath($freedomInstallPath)
  $freedomSetupPath = Join-Path (Get-Location) 'FreedomGPT-Setup-1.6.0.exe'
  $freedomHash = 'df9c9b031e7b72054248bdfb64002d7395c6164417d8bf28ae4b4a8ac12d8947'
  if (!(Test-Path -LiteralPath $freedomSetupPath) -or (Get-FileHash -LiteralPath $freedomSetupPath -Algorithm SHA256).Hash -ne $freedomHash) {
    curl.exe -fL -C - --retry 4 -o $freedomSetupPath 'https://github.com/Leongrupp/freedom-gpt/releases/download/v1.6.0/FreedomGPT-Setup-1.6.0.exe'
    if ($LASTEXITCODE -ne 0) { throw 'Download failed. Run again to resume.' }
  }
  if ((Get-FileHash -LiteralPath $freedomSetupPath -Algorithm SHA256).Hash -ne $freedomHash) { throw 'SHA256 mismatch. Installation stopped.' }
  $freedomProcess = Start-Process -FilePath $freedomSetupPath -ArgumentList ('/extract="' + $freedomInstallPath + '"') -Wait -PassThru
  if ($freedomProcess.ExitCode -ne 0) { throw 'Installation failed. Choose a new empty folder outside your user profile.' }
  Start-Process -FilePath (Join-Path $freedomInstallPath 'FreedomGPT.exe')
}

Если копирование по кнопке недоступно: «Выделить» → Ctrl+C (Cmd+C на Mac).

Выберите первую модель

Веса моделей не входят в установщик. Дождитесь проверки RAM, VRAM и диска и выберите подходящую модель. На ПК с небольшой памятью начните с лёгкого варианта. Для загрузки нужен интернет; затем локальный чат может работать офлайн. Размеры моделей и требования к памяти.
