# Freedom GPT

**Бесплатное локальное приложение для Windows: чаты, код, файлы и изображения на вашем компьютере.**

[Скачать для Windows](https://github.com/Leongrupp/freedom-gpt/releases/latest) · [English](README.md) · [Участие в разработке](CONTRIBUTING.md)

## Что умеет

- Сохраняет чаты, работает с папками проектов, файлами и памятью проекта.
- Пишет код потоком, сохраняет отступы и позволяет копировать код одной кнопкой.
- Показывает токены в секунду, RAM, VRAM и загрузку GPU.
- Имеет режимы **Код — быстро**, **Обдумать** и **Изображение**.
- Определяет характеристики ПК, предлагает подходящие по памяти модели, продолжает прерванные загрузки и проверяет SHA256.
- Принимает совместимые GGUF и подключается к уже работающему локальному API.
- Переключается между русским и английским интерфейсом.
- Автоматически получает подписанные обновления между задачами. Модели, чаты, настройки и рабочие файлы сохраняются. Автообновление можно отключить.

## Установка

1. Откройте [последний релиз](https://github.com/Leongrupp/freedom-gpt/releases/latest) и скачайте **FreedomGPT-Setup-1.2.0.exe**.
2. Выберите **Русский** или **English** и новую пустую папку на внутреннем или внешнем SSD.
3. Запустите **FreedomGPT.exe** или созданный ярлык.
4. Приложение проверит CPU, RAM, видеопамять NVIDIA и свободный диск. Выберите модель, нажмите **Скачать модель** и дождитесь проверки.
5. Нажмите **Использовать модель** и создайте чат. Для рисования нужен отдельный комплект Qwen Image.

Можно распаковать ZIP целиком вместо установки. Python и локальные движки уже включены. Нужны Windows 10/11 x64, современный Edge/Chrome и актуальный драйвер NVIDIA для ускорения. Другие видеокарты в этой версии используют CPU.

Установщик **не подписан сертификатом Authenticode**. Подпись манифеста автообновления не является цифровой подписью Windows-издателя. Не отключайте защиту Windows ради установки.

## Модели и требования

| Вариант | Модель | Предварительный ориентир |
|---|---|---|
| Стандартный код | Huihui Qwen3.8 Coder 27B IQ3_S3 с визуальным проектором | 32 ГБ RAM, NVIDIA 16 ГБ VRAM |
| Изображения | Qwen Image 2.1 Turbo Q5_K_M + энкодер + VAE | NVIDIA 12–16 ГБ VRAM |
| Легче | Qwen3.5 4B Q4_K_M | 12–16 ГБ RAM, возможности слабее |
| Минимальный | Qwen3.5 0.8B Q4_K_M | 8 ГБ RAM, ограниченная работа с кодом и инструментами |

Модели скачиваются отдельно. Стандартный комплект весов — около **24,3 ГБ**. Планируйте **от 35 ГБ свободного SSD** с запасом для приложения, временных загрузок и обновлений. Оценка по памяти не гарантирует скорость.

Импорт поддерживает единый GGUF с исходным контекстом от 64К и совместимой архитектурой. Анализ фото требует модели с визуальным проектором. Лёгкие модели и работа на CPU заметно уступают стандартной конфигурации.

## Без интернета

После загрузки моделей локальные чаты, история и файлы работают без сети. Интернет нужен для скачиваний, проверки обновлений, поиска и внешних сайтов. API слушает только **127.0.0.1**.

Все данные находятся внутри выбранной папки. Перед отключением SSD выполните **Stop-FreedomGPT.cmd**. Драйвер GPU устанавливается на сам компьютер. Не запускайте одну базу одновременно с двух ПК.

## Скорость и качество

На ПК разработчика — RTX 4080 16 ГБ, Ryzen 9 7900X, 32 ГБ RAM — длинный кодовый ответ на 2016 токенов выдан со скоростью **100,85 токена/с**, следующий — **102,34**. Отдельный прямой тест движка дал 135,36. При 61К входа один тест дал 88,10 токена/с.

Это результаты конкретных задач без времени чтения контекста и работы инструментов. Постоянные 100+ на любом ПК не обещаются. Модель может ошибаться: проверяйте код тестами, для сложной логики включайте **Обдумать**. Память проекта не заменяет Git и резервные копии.

## Обновления и исходники

Новые опубликованные версии автоматически скачиваются и устанавливаются, когда задачи завершены. Проверяются подпись Ed25519, SHA256 пакета и хеши файлов. Предыдущие изменяемые файлы приложения сохраняются в резервной копии. При отсутствии сети проверка повторяется позже.

Публикация коммита сама по себе не обновляет клиентов: разработчик выпускает проверенный подписанный релиз. Сборка и команда выпуска описаны в [BUILD.md](BUILD.md).

Локальный двуязычный сайт запускается через **Start-Website.cmd**. Публичный сервер настраивается отдельно.
